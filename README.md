## 🌱 Open source

I contribute to [**Blamely**](https://blamely.ai) — line-level AI vs Human code attribution. `git blame` shows who *committed* a line; Blamely shows who *wrote* it — a human or an AI assistant. Go CLI + attribution daemon, JetBrains & VS Code extensions.
